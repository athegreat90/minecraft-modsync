Account status

Disabling blocks every sign-in and ends all sessions and tokens. Devices stay registered, so enabling the account again restores access.

This account cannot sign in or use any token until it is enabled again.

Reset password

Passwords need 16 to 256 characters. The account's sessions and tokens end, so its clients must sign in again.

Sessions and devices

Ends every session and token. Devices stay valid and clients sign in again.

Permanently revokes all devices. A revoked device id can never sign in again, so each client must register with a new one.
